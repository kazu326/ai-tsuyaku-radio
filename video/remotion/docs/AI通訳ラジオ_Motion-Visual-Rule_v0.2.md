# AI通訳ラジオ｜Motion / Visual Rule v0.2

## 目的

AI通訳ラジオの映像を、音声理解を邪魔せず、必要な箇所だけ視覚的に補助するための現時点の確定ルール。

---

## 1. Background

### Background Playlist Baseline v0.3

- A / B / C は素材選択Pool
- A / B / C は厳密な前半・中盤・後半固定ではない
- 導入は必ずAから選ぶ
- Aの中では前半向き素材を優先する
- その後はA / B / Cを自由に行き来できる
- 同一素材の連続使用は避ける
- 同一Poolが過度に連続しないようにする
- 切替は短いCrossfadeを使用する
- Backgroundは意味を説明する主役ではなく、音声を邪魔しない環境として扱う

### Loop管理

素材ごとに `loopable` を持つ。

- `YES`：必要に応じてループ可
- `NO`：ループさせない

Loop可否は素材の意味・動作を見て判断する。

例：
- 空、雨、水面など → Loopしやすい
- 扉を開けて中に入る等、始点と終点が明確な一方向動作 → Loopしない

管理：
- `docs/background-assets-v0.1.md`：人間・AI向け台帳
- `src/data/background-assets.ts`：Remotion実行用

## 2. Subtitle

### Baseline

- 1280×720基準
- 左寄せ固定
- 白文字
- 通常28px
- 左側に細い縦バー
- 黒背景マスク 60%
- 位置：
  - left: 240
  - bottom: 30
  - width: 920
  - height: 150
- 文字数は固定値より自然な意味区切りと実際の表示幅を優先する
- 強調32px / Boldは標準では使用しない

字幕は読むための補助であり、説明Visualと役割を競合させない。

## 3. SE

### Cognitive Punctuation / 理解再同期Cue

SEは視聴維持のための刺激ではなく、意味の切り替わりを自然に知らせるCueとして使う。

### 現時点のBaseline

- 明るい短い「ピコン / キラン」系
- volume: 0.08 を基準
- 次のVisualやセリフに少し先行して鳴る
- ただしVisualとの距離が空きすぎない
- 同一意味クラスター内では原則として1回

成功条件：
- 普段は強く意識されない
- 注意が逸れていた場合は自然に次の意味へ戻れる
- 連続して鳴りすぎない

## 4. Panel Motion

### Entry

基本原則：

**「気づくけど、待たされない」**

- パネルは中央から横方向へ展開
- パネルと文字・画像は別レイヤー
- 文字や画像をパネルと一緒にScaleしない
- パネル展開後、文字・画像が自然にFade In

### Exit

突然消さない。

```text
文字・画像 Fade Out
↓
パネルが中央へ畳まれる
↓
Backgroundへ戻る
```

## 5. Meaning Cluster

映像演出の基本単位はセリフではなく意味クラスター。

### 基本

```text
意味クラスター開始
↓
必要ならSE
↓
Visual Containerを開く
↓
同一クラスター内は中身だけ更新
↓
意味クラスター終了
↓
Visual Containerを閉じる
```

### 確認済み例

CPU / GPU比較：

- SE 1回
- パネル開閉1回
- CPU → GPUは中身だけクロスフェード
- この方式をBaselineとして採用

---

## 6. Visual Type

現時点では黒い横長パネルを共通Containerとして使用する。

将来的には意味クラスターの理解目的に応じてVisual Typeを選択する。

候補：

- 比較 → 左右比較 / 棒グラフ / 1 vs 1000
- 流れ → フロー図
- 構造 → 図解
- 実物 → 画像 / 動画
- 数値差 → 棒グラフ
- 時系列 → タイムライン
- 概念整理 → Text Panel

ただし、現時点ではVisual Typeを固定ルール化しない。

---

## 7. 優先順位

映像演出で迷った場合は、次の順で判断する。

1. 視聴者が意味を理解しやすいか
2. 音声理解を邪魔しないか
3. 意味クラスターと演出単位が一致しているか
4. 素材の自然さ
5. 見た目の演出性

派手さや視聴維持テクニックを優先しない。
