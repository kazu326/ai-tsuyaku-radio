## Meaning Structure

| Macro Cluster | 理解目的 | 表示のまとまり |
|---|---|---|
| M1：答えから作業へ | 会議室探しを任せるイメージを作る | 導入背景 → V1：依頼の比較 |
| M2：結果を見ながら進める | 会議室の例から、行動・道具・確認の繰り返しを理解する | V2：会議室探し → 背景で橋渡し → V3：仕組みの整理 |
| M3：任せる範囲 | できることには条件があり、人の確認範囲を決めて使うと理解する | 背景で注意点 → V4：任せる範囲 → 背景 → V5：結論 → 背景 |

V2は具体例、V3は抽象化という理解目的の切り替えで分ける。同じM2でも開き直す理由は秒数ではなく、例をいったん受け止めて仕組みを整理するため。背景の間は音声の自然な間に合わせ、映像都合で長く引き延ばさない。

## 共通演出の適用

- Background Playlist v0.3と既存Asset Registryを使用。A開始、同一素材連続を避け、Poolの過度な連続を避ける。短いCrossfade、loopable判定を維持。
- Subtitle Baselineを維持。字幕の分割は自然な意味区切りと実表示幅で判断し、上表の行数とは一致させない。
- パネルと文字は別レイヤー。Entryは横展開と文字Fade In、Updateは中身だけ、Exitは文字Fade Out→パネルを畳む。
- SEは既存panel-cue.mp3、volume 0.08を基準にV1〜V4の開始時各1回。Visualに少し先行させるが、厳密な位置は実音声で確認。V5は鳴らさない。
- CATは今回の制作テストでは既存プレースホルダー。公開時の扱いは別途判断。

## 素材・実装の判断

| 区分 | 今回の扱い |
|---|---|
| そのまま再利用 | 背景素材、Registry、背景選択、字幕の外観、SE、パネル開閉の共通Motion、CATプレースホルダー |
| 小さな実装変更 | 今回用の文字パネル内容、既存フロー図の文言と強調切替、結論文、字幕・Visualタイムライン、今回用Composition。CPU/GPU専用表示をそのまま流用できるわけではなく、必要な範囲で既存レイアウトを転用する |
| 新規で必要 | この台本のElevenLabs音声と、その実尺に合わせた字幕時刻。音声ファイル名は配置時に実ファイルと一致させる |
| 必須の不足なし | 会議室の写真・動画、実サービス画面、新しいVisual Type。文字と既存図解で成立させる |

## 次の工程と確認

1. 台本の説明内容と、Macro Cluster / Visual Segmentの自然さを確認する。Motionや素材選択の細部は上記判断で進められる。
2. 従来のElevenLabsで本文を音声化し、publicへ手動配置。試聴して約3分の目標との違いを確認し、必要なら台本を短縮・調整する。
3. 実音声に合わせて字幕・Visualの時刻を設定する。既存MVPの130秒と末尾表示のズレは既知の修正対象であり、今回も固定秒数だけで終端を決めない。既存MVPの修正は本書作成時点では未実施。
4. 実装・レンダー後、音声のみで説明が通るか、図解が理解を補助するか、V2の再検索とV3の反復が伝わるかを確認する。既存PASS条件に沿って字幕・SEの同期、背景切替、パネルの連続性、最後まで表示が完了することも確認する。

現段階で追加の素材や演出方針について人間の決定待ちはない。実音声が届くまでは最終尺・同期位置を確定しない。
