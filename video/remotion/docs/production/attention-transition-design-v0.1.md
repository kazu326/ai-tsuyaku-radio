# AI通訳ラジオ｜Attention / Transition Design v0.1

## 目的

アニメーション、SE、強調文字、画像切替は装飾として使わない。

「話題が切り替わった」「ここは重要」「ここで注意を戻して聞く」という情報を、視覚・聴覚的に自然に伝え、聞きやすさ・理解・記憶を助けるために使う。

AI通訳ラジオはラジオ主体である。通常時は音声、字幕、背景、猫小窓を静かに保ち、意味のある箇所だけ変化させる。

## 背景となる考え方

会話では、間、フィラー、声やテンポの変化、身振り、視線から、話の継続・転換・重要度を受け取る。動画のSE、アニメーション、画像切替、強調文字は、その一部を補う。

演出の採否は、派手になるかではなく、視聴者の理解や注意の切り替えを助けるかで判断する。

## 使う箇所

次の箇所で、必要に応じて視覚または聴覚キューを加える。

- 大きな話題転換
- 新しい概念へ入る箇所
- 比較を始める箇所
- 音声だけではイメージしにくい説明
- この回で特に覚えてほしい部分
- まとめ、または重要な再確認

## 現在の推奨例

現在の有力な軽量パターンは、**中央から横へ展開する説明パネル**である。

背景 → 短いSE → 中央からパネルを左右へ展開 → 文字・図を表示 → 説明中はパネルを維持 → 必要なら中身だけ更新 → 内容をFade Out → パネルを中央へ畳む → 背景へ戻る。

これは唯一の固定演出ではない。より軽く理解しやすい方法があれば変更してよい。ただし、ラジオ主体の動画で常に画面を動かすことは目的にしない。

## SE

SEは話題の切り替わりを耳で知らせるために使う。候補は、セリフ開始の少し前、目安として約300ms前後からパネル展開と連動する短い音である。

「ポン」「シュッ」「パン」、指を鳴らすような短い音が候補。種類、音量、開始時刻は固定しない。音声理解を邪魔しないことを優先する。

## 変更可能な部分

固定するのは、話題転換や重要箇所を認識しやすくし、聞きやすさ・理解・記憶を助け、通常状態との差で注意の合図として機能させる目的である。

次は内容に応じて変更できる。

- 中央展開を使うかどうか
- アニメーション、Fade、パネルの秒数・サイズ
- SEの種類・音量・開始時刻
- パネル展開、画像表示、大きな短文、軽いFade、SEのみの使い分け

同じ動きやSEを機械的に繰り返さない。演出を入れない場合も、話題転換や重要箇所が十分認識できるか確認する。

## 実装と確認

実装では、回の内容を見て「どこで注意を戻す必要があるか」「どの合図が最も軽く自然か」を判断する。過去とまったく同じモーションを再現すること自体は目的にしない。

コードだけで完了としない。Remotion Studioまたは完成動画を人間が確認し、次を評価する。

- 突然現れて見にくくないか
- 話題が変わったことを自然に感じるか
- 重要箇所で注意が少し戻るか
- SEがセリフを邪魔していないか
- 演出が多すぎて疲れないか

見た目の派手さではなく、聞きやすさ・理解しやすさを評価する。

### 章タイトルの前面表示

- 章や大きなセクションのタイトルを読み上げる瞬間に同期する。
- 最前面へ大きなタイトルを一時表示し、「ここから話の展開が変わる」という注意転換のフラグにする。
- 字幕を読めなくしないこと、タイトルの表示が説明開始を遅らせないこと、毎回の反復が重くならないことを確認する。

### 方向を持つ図解

- 起点と到達点がある関係を、単なる線や配色だけで示さない。
- 矢印を使うか、起点を先に見せて到達点へ流す段階アニメーションで方向を明示する。
- 色・大きさ・コントラストによる最初の注視点が、意図する読み順と一致しているか確認する。
- 音声を聞かなくても、少なくとも流れの向きが誤読されにくい状態を目指す。
