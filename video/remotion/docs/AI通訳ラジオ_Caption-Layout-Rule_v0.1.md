# AI通訳ラジオ｜Caption Layout Rule v0.1

## 1. 目的

字幕は、音声の内容をそのまま画面へ並べるためのものではありません。

目的は、

**音声を聞きながら、視線を止めずに内容を追えるようにすること**

です。

AI通訳ラジオでは音声だけでも内容が理解できることを前提とし、字幕は理解・聞き取り・現在地の把握を補助します。

## 2. 最重要原則

### 音声同期と字幕レイアウトを分けて考える

字幕には少なくとも二つの判断があります。

1. いつ表示するか
2. どう改行して見せるか

発話時刻が正しくても、改行が不自然なら読みづらくなります。

そのため、**ASRやタイムスタンプで表示時刻を決めた後、画面上の改行は別工程として判断する**ことを基本とします。

## 3. 字幕レイアウトの判定順

まず改行の必要性を判断し、2行が必要な場合に意味の区切りと上下のバランスを整えます。以下は判断の手順であり、文字数の固定制約を増やすものではありません。

1. **まず1行で表示できるか確認する。**
2. 実際のフォント・サイズ・字幕本文領域の幅に収まり、おおむね35文字程度以内なら、原則として改行しない。
3. 1行では長すぎる場合だけ2行にする。意味の区切りがあるという理由だけでは改行しない。
4. 2行にする場合は、日本語として自然な意味の区切りを選ぶ。
5. 助詞・句読点・1〜3文字だけを下段に残さない。
6. 自然な意味の区切りを保てる候補の中で、上段をやや長く、下段をやや短くする配置を優先する。語順や表現は変えない。
7. 文字数だけで合否を決めず、最終的な実表示を見て確認する。

35文字は目安です。35文字以内でも実表示幅を超えれば2行を検討し、35文字を超えても自然に読める場合は実表示で判断します。文字を縮めて1行へ押し込むことはしません。

避ける例：
- 最後の1文字だけ2行目へ送る
- 助詞だけを次の行へ送る
- 句読点だけを次の行へ送る
- 一つの意味のまとまりを不自然な位置で切る
- 数字と単位、固有名詞、短い専門語を不用意に分割する

## 4. 文字量の目安

現在のBaselineでは、

- 通常文字：28px
- 左寄せ固定
- まず1行を優先し、必要な場合だけ2行
- 1つの字幕ブロックは、おおむね20〜30文字程度を中心に考える
- 35文字程度を超える場合は、意味と表示幅を見て改行または字幕ブロックの分割を検討する。ブロックを分ける場合は音声同期も確認する
- 状況によっては40文字前後でも、実表示が自然なら許容する

とします。

ただし、これらは固定制約ではありません。

**「何文字か」より「一瞬見て自然に読めるか」を優先します。**

## 5. 2行字幕のバランス

2行になる場合は、上下を機械的に同じ長さへ揃えません。

基本は、

- 1行目に主要な意味のまとまり
- 2行目に残りの意味を自然に収める
- 極端に短い2行目を作らない
- 2行目が1〜3文字程度しか残らない場合は、前の区切りから再調整する

とします。

自然な意味の区切りを保てる範囲で、1行目をやや長く、2行目をやや短くする配置を優先します。意味を壊してまで揃えません。

## 6. 字幕本文の扱い

字幕は採用済み台本の内容を基準とします。

ASRで誤認識した文字列をそのまま字幕へ転記しません。

タイムスタンプ取得のためにASRを使った場合でも、**表示する本文は採用済み台本と照合する**ことを基本とします。

改行のために語順や表現を勝手に書き換えません。どうしても表示上の問題がある場合は、台本修正として別判断します。

## 7. 字幕とVisualの関係

字幕と説明パネルは同じ役割ではありません。

- 字幕：今しゃべっている内容を追う
- Visual：比較、関係、流れ、数量、実物イメージなどを理解する

説明パネルへ字幕全文を重ねて載せる必要はありません。

Visualに文字を置く場合は、**字幕と同じ文章を繰り返すのではなく、理解に必要な短い語句だけを使う**ことを基本とします。

## 8. 強調

### 黒いマスク背景の表示

黒いマスク背景は、字幕の有無にかかわらず動画全体で常時表示します。発話の間、冒頭・末尾も消さず、音声同期で切り替えるのは文字だけとします。字幕区間ごとにマスクを出し入れして、点滅して見える状態を避けます。

既存Baselineの位置・幅・高さ・不透明度は維持し、1行・2行の切り替えでもマスクの大きさを変えません。

### 文字の強調

通常字幕の中で、文字サイズ・色・太字を頻繁に変えません。

強調したい情報がある場合は、別Visual、短いキーワード表示、図解、数字表示などを優先します。

字幕そのものを派手にすることを、視聴維持の手段として使いません。

## 9. AIが字幕を作るときの判断

AIは、以下を自律的に判断して構いません。

- 自然な字幕区切り
- 1行 / 2行
- 意味のまとまりに沿った改行
- 1〜3文字だけ残る孤立行の回避
- 実表示幅に合わせた再配置

ただし、台本本文の意味を変更する、勝手に要約する、強調表現を大量に追加することはしません。

## 10. 最終確認

- 音声と大きくズレていないか
- 1行で自然に収まる字幕を、不要に2行へ分けていないか
- 最後の1文字・助詞・句読点だけが次行に残っていないか
- 一度に読む量が多すぎないか
- 自然な意味のまとまりで改行されているか
- 字幕とVisualが同じ情報を過剰に重複していないか
- 最後の字幕が動画終端内に収まっているか
- 字幕の間や末尾でも黒いマスクが消えず、点滅して見えないか
- 実際に通して見たとき、字幕を読むことが主作業になっていないか

## 11. 判断原則

字幕設計では、**1行で自然に収まるか → 必要な場合だけ2行 → 意味の区切り → 上下のバランス → 実表示確認**の順で判断します。意味の自然さと視認性を保ち、文字数は補助指標として扱います。

固定の文字数ルールを守ることより、**音声を聞きながら自然に目で追えること**を優先します。
