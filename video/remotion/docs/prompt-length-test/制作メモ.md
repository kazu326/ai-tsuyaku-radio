## 制作判断

- 核心：目的と必要な情報を共有し、やり取りで狙いに近づける。
- ユーザー提供本文をそのまま採用。言い換え、補足、次回予告の追加はしない。

- 映像は背景と字幕のみ。CAT・説明Visual・画像・SE・BGMは追加しない。
- Caption Layout Ruleに従い、字幕は白28px、左寄せ、既存マスク・位置を維持。意味のまとまりで1〜2行にし、明示した改行を表示側でも保持する。
- 実音声87.248938秒に約1秒の余韻を加え、88.266667秒／2648フレーム／30fps。採用本文の短縮や音声の速度変更は行わない。
- Model / Resource Policyに従い、この回に必要な静的データと既存部品の再利用に留める。API連携や新しい自動化基盤は追加しない。

## 2026-09-07：V03人間視聴結果・暫定ベースライン採用

Forced Alignmentの生タイムスタンプをそのまま表示すると、字幕が発声より若干遅れて感じられた。字幕間の重なりを避ける調整を行った結果、短文は発声付近、長文はやや早めに全文表示される挙動となった。意図的に文章長別のオフセットを設計したものではないが、人間視聴ではこれまでで最も読みやすい結果となった。長尺・一文一括字幕の暫定ベースラインとして採用する。

上記はユーザーの視聴所感と採用判断。実装上は、V02の保存済み字幕時刻に対して全27区間の開始を一律300ms前倒しし、0秒未満は0秒に丸めた。終了時刻データは維持し、重なり区間では次字幕を優先する。短文／長文別の分岐やオフセットはない。文章長による見え方の違いは観察結果として記録し、因果や一般的な最適値が実証されたとは扱わない。

ここでいう「生タイムスタンプ」は開始の前倒しを加える前のV02を指す。V02にも既存27ブロックへの対応付けと末尾150ms保持などの表示用処理はある。V03ではAPI再送信・音声再解析を行わず、この保存済み結果を再利用した。
