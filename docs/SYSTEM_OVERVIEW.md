# AI通訳ラジオ｜AIネイティブ本社 全体像

Status: Draft for review / 2026-10-01

## 何を作ろうとしているか

AI通訳ラジオは、AIを解説するメディアであると同時に、**人間とAIが実際に一緒に働く小さな組織そのものを実験する場所**として育てる。

中心にあるのはGitHub上のAI通訳ラジオ本体。Cloudflareを「本社の入口」にし、現実の人間はCodex、Claudeなど自分に合うAI作業環境から同じ会社へ入れるようにする。

一般の人は公開コンテンツを見る。内部メンバーは認証後に必要な情報やツールへアクセスし、将来的には軽量な3D本社で互いの存在や活動を感じながら働けるようにする。

## それぞれの役割

### GitHub

会社の正本。

- 現在地
- 決定事項
- Knowledge
- Episode
- 世界設定
- コード
- 制作物
- Observation
- PR

を残す。

### Cloudflare

会社の入口。

一般公開と内部アクセスを分け、内部メンバーには認証された入口を用意する。MCPを通じて、CodexやClaudeなど異なるAIクライアントから同じ会社へ入れる状態を目指す。

### MCP

「AIに会社の情報と道具を渡す共通窓口」。

AIごとに別の会社を作らず、必要なContext、Search、Task、PRなどを共通インターフェースで提供する。

### 3D Presence

仕事そのものを3Dゲームへ置き換えるものではない。

目的は、

- 誰がいるか
- どこにいるか
- 何をしているか
- 話しかけられそうか

を直感的に感じられるようにし、リモート作業の孤独感やコミュニケーションの摩擦を減らせるか試すこと。

フォトリアルは狙わない。軽量でゲームらしい、長時間開いても疲れにくい表現を優先する。

### Real Member / Seed / Actor

```text
Real Member
  ↓
World Model Seed
  ↓ 実務で成長
必要なら
  ↓
Actor
```

人間が責任を持ち、その配下でSeedが仕事を学ぶ。外へ出る必要がなければSeedのままでよい。動画、SNS、一般ユーザーとの会話など外部との接点が必要になったときだけActorを持つ。

## なぜこれを作るか

目的は「未来っぽい会社を見せること」ではない。

実際に少人数で使い、

- AIと働くと何が楽になるか
- 逆に何が疲れるか
- 人間のレビュー速度がどこでボトルネックになるか
- 複数AIをまたぐと何が必要になるか
- リモートでも一体感を感じられるか
- 柔軟な時間・場所で仕事へ参加しやすくなるか

を観察する。

その経験そのものをKnowledgeにし、AI通訳ラジオの記事・動画・実験コンテンツへ戻す。

## 今は作らないもの

- 大人数向けの完成した仮想オフィス
- フォトリアルなメタバース
- 全AIのキャラクター化
- 巨大な権限管理システム
- 完全自動経営
- 収益化を前提にした複雑なSaaS

必要性が確認されたものだけ段階的に作る。
