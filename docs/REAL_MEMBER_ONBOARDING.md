# AI通訳ラジオ｜Real Member Onboarding v0.2

Status: Draft for review / 2026-10-02  
Audience: AI通訳ラジオに新しく参加する現実の人

## 1. ようこそ

AI通訳ラジオでは、最初からAIに詳しいことを前提にしません。

ここは、AIについて発信するメディアであると同時に、**人間とAIエージェントが実際に何かをやりながら一緒に成長する場所**です。

最初に決めるのは、動画や記事の担当ではありません。

**「AIを使って、何をやってみたいですか？」**

から始めます。

---

## 2. やることはAI通訳ラジオ内だけで完結しなくてよい

例えば、

- SNSをやってみたい
- AIアプリを作りたい
- Webサービスを作りたい
- 動画や記事を作りたい
- 商品を企画して外注したい
- 3Dプリンターで何か作りたい
- AIを使ってハードウェアを設計したい
- 自分で組み立てて実験したい
- ECで販売してみたい
- クラウドファンディングを試したい
- まだ何をしたいか分からない

でも構いません。

AI通訳ラジオに必要な仕事へ自分を合わせるのではなく、まず本人の興味や目的から小さなExperimentを作ります。

その経験が、あとからAI通訳ラジオのKnowledgeやコンテンツになることがあります。

---

## 3. Real Memberとは

あなた自身は架空のキャラクターではありません。

Real Memberとして、

- 実際にやったこと
- 実際に判断したこと
- 実際に困ったこと
- 実際に学んだこと

を活動の記録として扱います。

AIがあなたの性格、能力、感情、事情を勝手に設定することはしません。

---

## 4. WorldModelSeedとは

あなたの周辺には、必要に応じてWorldModelSeedを置きます。

Seedは完成済みの「AI社員」ではありません。

あなたが何かを実際に行い、

```text
やりたいこと
  ↓
試す
  ↓
結果を見る
  ↓
失敗や成功を記録する
  ↓
AIと原因を考える
  ↓
必要なContextや境界を直す
  ↓
また試す
```

という循環を通して、あなたと一緒に育つAI作業基盤です。

詳しい設計は `../context/WORLD_MODEL_SEED.md` を参照してください。

---

## 5. すでに経験やKnowledgeがある場合

ゼロから始める必要はありません。

すでに、

- 過去の仕事
- 資料
- 制作物
- 手順
- 成功例
- 失敗例
- 自分なりの判断基準

がある場合、それらはSeedの初期Context候補になります。

「新しいAIのやり方へ全部合わせる」のではなく、**今まで持っている経験をAgentが使える形にする**こともWorldModelSeedの役割です。

---

## 6. まだ何をしたいか決まっていない場合

決まっていなくても参加できます。

AIと一緒に、

1. 興味があることをいくつか出す
2. その中から短期間で試せるものを選ぶ
3. 小さなExperimentを一つ実行する
4. 実際にやってみた感触から次を決める

という形で探索します。

最初から将来の職種や専門分野を決める必要はありません。

---

## 7. 最初のPC準備

現在はGitHubがAI通訳ラジオのSource of Truthです。

最低限、次を用意します。

- GitHubアカウント
- このリポジトリへの必要なアクセス権
- Git
- 自分が使うAIクライアント
  - Codex
  - Claude / Claude Code
  - 将来対応する別のクライアント

将来的にはCloudflare上の本社入口から参加できる状態を目指しますが、現時点ではGitHubから始めます。

---

## 8. リポジトリを自分のPCへ取得する

通常の初参加ではworktreeを必須にしません。

自分のPCへ独立してcloneします。

```bash
git clone https://github.com/kazu326/ai-tsuyaku-radio.git
cd ai-tsuyaku-radio
```

アクセス方法がSSHで統一された場合は、チームで指定されたclone方法を優先します。

その後、自分の作業ブランチを作ります。

```bash
git switch -c <your-work-branch>
```

branch名は作業内容が分かる短い名前にします。

---

## 9. Codex / Claudeで開く

cloneした `ai-tsuyaku-radio` フォルダを、自分のCodexまたはClaude Codeから開きます。

AI側はまず、

1. `AGENTS.md`
2. `README.md`
3. `context/CURRENT.md`
4. `context/WORLD_MODEL_SEED.md`
5. 今回のTaskに必要な資料

を確認します。

最初の会話は、例えば次の程度で構いません。

> このリポジトリの作業方針を確認してください。私は新しいReal Memberです。まず、AIを使って何をやってみたいか整理し、最初の小さなExperimentを一緒に決めてください。必要なContextだけ読んでください。

特別なPromptを暗記する必要はありません。

---

## 10. 最初のExperiment

最初から大きな成果物を完成させる必要はありません。

まず、

**「短期間で実際に試せて、結果が観察できること」**

を一つ選びます。

例：

- SNS投稿を3本作り反応を見る
- 小さなAIツールを1つ作る
- 3Dプリンターで小さな試作品を作る
- 外注用仕様書をAIと作る
- 既存の自分の作業をAIで一工程だけ改善する
- 過去の資料をSeed用Contextとして整理する

Experimentの結果は成功でなくても構いません。

---

## 11. Task Contract

作業を始める前に、AIと最低限次を共有します。

- Purpose — 今回何を成功とするか
- Boundary — どこまで触ってよいか
- Context — 何を判断材料にするか
- Authority — AIがどこまで実行してよいか
- Evaluation — 何を見て結果を判断するか
- Human Approval — どこで人間確認するか
- Unknown — まだ決まっていないこと

重い書類を毎回作る必要はありません。

小さなTaskなら数行でも構いません。

---

## 12. AIが「この条件では難しい」と言った場合

現在のBoundaryやAuthorityでは目的達成が難しい場合、AIは勝手に範囲を広げるのではなくChallengeを出します。

例えば、

- 必要な資料がない
- 権限が足りない
- 変更禁止範囲を触らないと目的を達成しづらい
- 完了条件が曖昧

など。

Challengeが出たら、Real Memberと一緒にContractを見直します。

---

## 13. 基本のGitHub運用

原則：

```text
作業ブランチ
  ↓
変更
  ↓
commit
  ↓
push
  ↓
PR
  ↓
レビュー
  ↓
main
```

mainを直接大きく変更しません。

AIが変更を提案した場合も、何を変えたか分からないまま大量に進めず、理解できる単位でレビューします。

---

## 14. 作業記録

長い日報は不要です。

最低限、

- 何をしようとした？
- 何が起きた？
- 予想外だったことは？
- どう判断した？
- 次に使えそうなKnowledgeは？

があれば十分です。

うまくいかなかったことも重要なObservationです。

---

## 15. Knowledgeと権限

内部だからといって、全員がすべての情報へアクセスするわけではありません。

Knowledgeには、

- Public
- Internal Shared
- Role Scoped
- Personal
- Client
- Protected

などのScopeがあります。

詳しくは `../context/KNOWLEDGE_MODEL.md` を参照してください。

「AIが知っていること」と「外へ出してよいこと」も別です。

---

## 16. 成長の考え方

目標は、AIの使い方を暗記することだけではありません。

実践を通して、

- 何をAIへ任せるか
- 何を人間が確認するか
- Contextをどう用意するか
- 失敗の原因をどう切り分けるか
- 権限をどう設定するか
- 良い結果をどう評価するか
- 自分のAgentをどう育てるか

を身につけていきます。

AI通訳ラジオは、この実践を通してAIエンジニアリング的な判断力を育てる組織でもありたいと考えています。

---

## 17. AI通訳ラジオへの還元

あなたのExperimentが、そのまま動画や記事になる必要はありません。

ただし面白い経験や再利用可能なKnowledgeが生まれた場合、

- YouTube
- Web記事
- SNS
- GitHub
- 制作ログ
- イベント
- 別のExperiment

などへ翻訳することがあります。

**実際にやった経験を、後から社会へ通訳する。**

これもAI通訳ラジオの役割です。

---

## 18. 分からないとき

「分からない」は正常です。

WorldModelSeedもAI通訳ラジオも完成品ではありません。

使いにくかった場所、理解できなかった場所、AIが間違えた場所は、仕組みを改善するための重要なObservationです。

最初から完璧に理解するより、まず小さく一周してください。
