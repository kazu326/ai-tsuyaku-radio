# VISION｜AI通訳ラジオが目指す長期像 v0.1

Status: Direction / Hypotheses to test  
Updated: 2026-10-01

## 現在の中心

AI通訳ラジオは、AIニュースや技術を一般の人へ翻訳するメディア。

同時に、自分たち自身が人間とAIの新しい働き方を実際に試す、小さな実験組織として育てる。

さらに、Real Memberが自分の興味からExperimentを始め、WorldModelSeedと一緒に実践することで、AIエンジニアリング的な判断力を育てる組織でもありたい。

動画・記事・Web制作だけを活動範囲にせず、SNS、ソフトウェア、ハードウェア、商品開発、3Dプリント、外注、販売、クラウドファンディングなど、AIを使った実践を広く対象にする。

「こうなるはず」と先に完成形を主張するのではなく、実際に運営し、失敗・改善・結果を記録する。

## 循環

```text
実際に働く
 ↓
問題・発見が起きる
 ↓
記録する
 ↓
Knowledgeにする
 ↓
AI通訳ラジオで発信する
 ↓
新しい人・仕事・問い合わせにつながる
 ↓
また実際の運営で検証する
```

## 収益化についての仮説

この仕組みを、検証前から固定商品として大量販売することは目的にしない。

まず自分たちで使い、公開できる範囲でExperiment、失敗、改善、結果を発信する。

その結果、

- 「うちの会社でもやりたい」
- 「自分でも自分のAIを育てられるようになりたい」
- 「既存の社内KnowledgeをAIが使える形にしたい」
- 「導入したAI Agentが現場に合わなくなっている」
- 「非エンジニアでも継続的に調整できる環境がほしい」

という需要につながるかを観察する。

将来の外部提供では、AI通訳ラジオ内部のAgentをそのまま配るのではなく、**企業・個人ごとにWorldModelSeedをカスタマイズする導入パッケージ**を事業仮説とする。

概念的には、

```text
WorldModelSeed Core
+
顧客の目的
+
既存Knowledge
+
Role / Permission
+
Personal Context
+
Evaluation
+
実運用から得たExperience
```

から顧客専用のWorld Modelを構築する。

価値は「完成したAI社員を納品すること」だけではなく、利用者側に**自分たちのAgentを育て続ける能力とKnowledgeを残すこと**に置く。

AI通訳ラジオ側だけが調整Knowledgeを持ち、顧客が永続的にベンダーへ修正依頼しないと使えない構造を理想としない。

導入支援、設計、研修、Agent / Harness / MCP等の実装支援は収益源になる可能性がある。

これは現時点の売上予測ではなく、**内部運営から検証する事業仮説**。

## 人が成長する場所としての仮説

Real Memberは、教材だけでAIを学ぶのではなく、実際の仕事でAIを使う。

その過程で、

- AIに何を任せるか
- 何を確認するか
- Contextをどう渡すか
- 失敗をどう直すか
- Source of Truthをどう保つか
- 権限と自律性をどう分けるか

といった実践的な知識を身につけられる可能性がある。

肩書きを先に与えるのではなく、実際の成果物と経験を通してAIエンジニアリング的な判断力が育つかを観察する。

## 柔軟な働き方と社会参加についての仮説

従来型の職場環境、固定時間、通勤、対面中心のコミュニケーションなどが大きな障壁になる人は実際にいる。

AI補助、非同期作業、好きな場所・時間から参加できる環境、Presenceによる緩やかなつながりを組み合わせることで、**一部の人にとって仕事へ参加しやすい選択肢を作れる可能性**を検証したい。

将来的には、障害のある人を含め、従来の働き方に適応しづらい人が、自分の得意なことや経験をKnowledgeへ変え、それが組織の価値や収益につながり、報酬へ戻る仕組みに発展できるかを考える。

ただし、

- 誰にでも合うとは仮定しない
- 障害や事情を一括りにしない
- AIが支援を代替できると断定しない
- 実際の参加者の意思、アクセシビリティ、負担、安全を優先する

## 組織化について

運営実績、収益、参加者、責任範囲が育ち、正式な組織が必要な段階になった場合に法人化や制度利用を検討する。

AI、雇用、障害者支援等に関する補助金・助成制度は、実際に申請を検討する時点の制度・要件を調査し、適格性を確認する。現時点では制度利用を前提に事業設計しない。

## 成功を測るときに見たいもの

売上だけでなく、次のような実測を残したい。

- Real Memberが継続して参加できたか
- AIを使う判断力が実務で育ったか
- 一人で抱える時間やコミュニケーション摩擦が減ったか
- Knowledgeが実際に再利用されたか
- 発信が新しい仕事や問い合わせにつながったか
- 報酬を持続的に還元できる経済性があるか
- 参加者の負担が増えすぎていないか
- 仕組みが人を固定・評価する方向へ暴走していないか

## 現時点の姿勢

大きな社会課題を解決したと先に言わない。

まず小さなチームで実際に使う。

良かったことも、機能しなかったことも記録する。

形になった部分だけを少しずつ外へ広げる。
