# BRAND｜AI通訳ラジオ デザインガイド（簡易版）

最終更新：2026-09-12
ステータス：現在のデフォルト

## 目的

「AIの難しい話を、わかる言葉に。」を視覚的にも表現する。

専門性は保ちつつ、難しそう・堅そうに見せない。「ラジオを聴くように気軽にAIを理解できる」世界観を基本とする。

## ブランドコンセプト

**AI通訳ラジオ**

**AIの難しい話を、わかる言葉に。**

難しいAIニュース・技術・業界動向を、専門知識がなくても理解できる言葉へ「通訳」する。

キーワード：やさしい / 知的 / 親しみやすい / ラジオ / 解説 / 学び / テクノロジー / 少し先の未来

## キャラクター

白黒のハチワレ猫。

実際の猫の白黒模様を基本に、イラスト表現ではヘッドセットを装着する。

役割は単なるマスコットや「AIに詳しい先生」ではなく、**人間とAIの間に立つ通訳者であり、ラジオパーソナリティ**。

- AI側の事情を人間の言葉へ翻訳する
- 人間がどこで分かりにくくなるかを猫の視点から拾う
- ときに人間とAIの両方を少し引いた猫の視点から観察する
- かわいさに寄せすぎず、知的さと親しみやすさを両立する

## 基本カラー

- メイン：深いネイビー〜ブルー
- アクセント：暖かいオレンジ〜アンバー
- ベース：ホワイト / オフホワイト
- 文字：ブラック / ダークネイビー

青は「AI・技術・知性」、オレンジは「ON AIR・照明・人間的な温かさ」を担当する。

赤 `#A90000` は基本カラーから外す。警告・強調など明確な意味がある場合のみ限定的に使用する。

## ビジュアル

ラジオスタジオを基本世界観とする。

使用要素：マイク / ヘッドセット / PC / ON AIRサイン / 吸音材 / 暖色のスタジオライト。

背景はブルー〜ネイビー、照明にはオレンジを入れ、寒色と暖色の対比をブランドの特徴にする。

## UI・レイアウト

- 基本背景：ホワイト〜オフホワイト
- 情報部分：整理されたシンプルな構成
- ネイビー：主要UIカラー
- オレンジ：CTA・選択・注目ポイント
- 装飾を増やすより、余白・文字サイズ・写真で情報の優先順位を作る
- カード、検索・絞り込み枠、情報パネル、画像など、構造を作る主要要素は原則として角丸にしない
- 円形は、ON AIRランプ、再生記号、状態表示など、形そのものに意味がある場合だけに限定する
- 大きな角丸、淡いグラデーション、浮遊するカード、過剰な影を組み合わせた汎用的な「AIサービス風UI」へ寄せない

ブランドボードのデフォルトは、白ベースの整理されたUIと、青＋オレンジのラジオスタジオ写真・キャラクターを組み合わせる方向。

### Web・UI赤ペン時の確認

- 角丸が、明確な意味や既存の確定ルールなしに追加されていないか
- 検索やフィルターが、本文・Episode画像・タイトルより先に目へ入る大きさになっていないか
- 「AIらしさ」を理由に、どのAIサービスにも見えるカード、影、グラデーション、装飾を足していないか
- 白、ネイビー、アンバー、直線的な区切り、余白による既存の情報階層を維持しているか
- 既存画面に角丸が残っていても、変更対象外へ無断で一括適用せず、対象範囲を確認して修正案として提示する

## タイポグラフィ

日本語は Noto Sans JP 系を基本とする。

- 見出し：Bold
- 本文：Regular
- 補足：Regular〜Light

キャッチコピーは短く、専門用語を並べない。

## コピー

代表コピー：**「AIの難しい話を、わかる言葉に。」**

コピーの変換軸：

- 難しい → わかる
- 専門的 → 身近
- AI → 人間の言葉

## ロゴ方向

現時点の採用方向は、**マイク＋猫耳＋猫の尻尾＋電波**を一体化したシンボル。

ネイビーを本体、オレンジを耳の内側や電波などのアクセントに使う。

細部は今後調整可能だが、このモチーフ構成を基本方向とする。

## デフォルト指定

「AI通訳ラジオのデフォルトデザイン」「いつもの方向」と指定された場合、次を基本セットとして使う。

**白黒ハチワレ猫 × ラジオスタジオ × ネイビー/ブルー × オレンジ照明 × 白ベースの整理されたUI**

YouTubeサムネイル、バナー、Web、SNS、説明図など媒体が変わっても、この世界観を維持する。
