# Web MVP トップページ調整レビュー

## トップ上部 PC仕上げレビュー（2026-10-01）

組み替えMVPを人間側で確認したところ、モバイルは問題なし。一方PCでは「凄そうだが少し素人っぽい」違和感があった。原因を次の2点と判断し、大改造はせずPC（幅901px以上）だけ仕上げた。

- 案内動画が、作り込んだ紺のセクションの中でブラウザ標準の動画プレイヤーのまま見えていた。
- 新しい上半分（映画・LP的な大きい見せ方）と、既存の下半分（編集メディア的でコンパクト）の情報密度の差。モバイルは1列で画面幅が狭いため、この差が見えない。

| 確認 | 結果 |
| --- | --- |
| lint / TypeScript | 成功 |
| 案内動画 | 再生前は中央を空けた専用ポスター＋再生ボタン（アンバーの円に紺の三角）だけを表示。クリックで音声ありの再生が始まり、標準コントロールはそこで初めて出ることを確認 |
| PC 1440px | Heroの高さ640px。ロゴが主役になりすぎず、1画面目の下端に案内動画の紺が見える |
| 通訳デモの改行 | 920 / 1100 / 1440pxで、言い換えが意味の切れ目だけで1〜2行に収まり、専門用語が列からはみ出さない |
| モバイル | 375pxで再生ボタンを小さくし、再生時間の表示を省略。横スクロールなし。それ以外のモバイル表示は変更なし |

### 調整内容（PC＝幅901px以上のみ）

- 上半分を締める：Heroの高さの上限 760px → 640px、ロゴの拡大上限 0.95 → 0.62。案内動画の上下余白 64px → 52px、列間 48px → 36px、見出しを既存セクションと同じ23pxに。通訳デモの横幅を1000pxに絞り、文字・マイクを約1割小さく。
- 下半分を広げる：3カテゴリーのカード間 8px → 14px、カード高 154px → 176px、見出し 14px → 15px、本文 11px → 12px、セクション余白を拡大。最新エピソード・お知らせの余白と、9〜12pxの小さい文字を1段ずつ上げた。
- いずれも10〜15%程度の変更に留めた。
- `guide-short-poster.jpg` は、中央を空けて手書きの締めを下に置いた再生前専用のポスターへ差し替えた（動画本体は変更なし）。最初は既存ポスターに紺の半透明を重ねたが、クリーム地と混ざって濁った灰色になり、ボタンが手書き文字に重なったため不採用。

### 残り

- Heroの専門用語は、レスポンシブのためランダム配置。PCでは余白が広く、配置の人工的なランダムさが見えやすい。必要ならPCだけ手で組んだ構図にする（未着手）。

## トップ上部 組み替えMVP レビュー（2026-09-30）

トップページ上部を「新Hero → 案内動画 → スクロール通訳 → 既存3カテゴリー」に組み替えた。第一段階として人間側で確定。細部（やや冷たく感じる箇所など）はまだ言語化できていないため、今後少しずつ調整する前提とする。トップ以外のページと、最新エピソード・お知らせ・ABOUTは変更していない。

| 確認 | 結果 |
| --- | --- |
| lint / TypeScript / 本番ビルド | すべて成功（全10ページを静的生成） |
| 新Hero | Canvasで「専門用語が画面を埋める → 『AIのニュース、むずかしすぎない？』 → 猫耳のないマイクが吸い込む → 猫耳が生えてロゴ」を約7秒で再生し、完成後にCTAと「もう一度見る」を表示。猫キャラクター本人は出さず、猫耳ロゴのみ使用 |
| 案内動画 | 約36秒・H.264/AAC・3.3MB。`preload="none"`、ポスター画像あり。Heroと重なる場面（専門用語・ロゴ登場）は入れていない |
| スクロール通訳 | 4例をスクロール量で進行・巻き戻し。1440px（横並び）と375px（縦並び）で表示を確認。言い換えは指定した意味の切れ目でだけ折り返し、375 / 820 / 920 / 1000 / 1100 / 1180 / 1280 / 1440 / 1920pxで1〜2行に収まることを実測 |
| 3カテゴリー | 3枚とも維持。「02 聞く」だけ、下端からスタジオのモニターがのぞき、ホバー・フォーカスで猫が映る。説明文は置いていない |
| 375px | ページ全体の横スクロールなし |
| 実行時 | コンソールのエラー・警告なし（開発サーバー） |

### 実装内容

- `components/home/translator-hero.tsx`：新Hero（Client Component / Canvas）。見出し・説明は視覚的に隠したHTMLにも置く。`prefers-reduced-motion`では完成形を静止表示。画面外では描画を止める。
- `components/home/guide-video.tsx`：案内動画セクション。
- `components/home/translation-scroll.tsx`：スクロール通訳（HTML要素＋CSS変数）。JavaScriptなし・動きを減らす設定では4組の一覧表示。言い換えの折り返し位置は `ITEMS` の `|` で指定する。
- `app/page.tsx`：旧ヒーロー（猫の写真）を上部から外し、3セクションを追加。`RadioMonitor` を「02 聞く」に追加。
- `app/globals.css`：追加分を末尾の「トップ上部 MVP」ブロックにまとめた。枠・カードは角丸なし、ネイビー／アンバーの既存階層を維持。

### 素材と境界

- `public/images/brand/`：正式ロゴ（猫耳あり・なしの2版、位置は完全一致）からクリーム背景を抜いて切り出したロゴ部品7点（マイク、猫耳マイク、猫耳、尻尾、ロゴ文字、タグライン、LET'S TALK AI）。
- `public/images/radio-monitor.jpg`：`hero-20260915.png` から猫の顔付近を切り出したもの。旧ヒーロー画像（Desktop / Mobile）は削除せず残し、今後ラジオセクション・Episode・猫のページで再利用を検討する。
- `public/video/guide-short.mp4` / `public/images/guide-short-poster.jpg`：CM（Canvas 2D、BGM「Lessons_in_Clarity」120BPM）の後半を小節線でつないだ短縮版。こんな人に → 「むずかしいを、やさしく。」 → ElevenLabs V4の女性音声「AIで、もっといい明日を。」。制作元はリポジトリ外の `canvas2Ｄ動画/cm_full.html?cut=short`。
- 案内動画は暫定。女性音声を「表側の案内役」として育てるため、30秒程度の専用ナレーション版へ差し替えるかを次に検討する。
- `review/verify.mjs` は今回の環境にPlaywrightがないため実行していない。reduced-motion表示は実装のみで、実ブラウザでの確認は未実施。
- 公開デプロイは行っていない。`noindex, nofollow` を維持。
