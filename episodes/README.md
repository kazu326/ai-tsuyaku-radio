# Episodes

各エピソードの制作パッケージを保存します。

推奨構成（必要なものだけ使用）：

```text
epXXX-topic/
├─ research.md
├─ script.md
├─ article.md
└─ social.md
```

順番は固定しません。動画先行・記事先行のどちらでも、同じテーマの成果物を一つのディレクトリへ集約します。

採用済みの16:9 Episode画像は `images/episode-XXX.png` に保存します。Web、動画、SNSへ展開する際の画像原本であり、画像の共通ルールと004以降の再利用手順は `context/EPISODE_IMAGE_RULES.md` を正本とします。
