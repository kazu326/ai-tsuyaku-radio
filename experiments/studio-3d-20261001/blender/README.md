## 開くファイル

`studio-finished-v01.blend` をBlenderの「ファイル → 開く」で選びます。元のGLBを再度読み込む必要はありません。読み込み済みの家具、窓、壁、4台のカメラ、素材と撮影照明を含みます。サインの画像はファイルに埋め込んであります。

- 起動時のカメラ：`cam_front`。数字テンキーの `0` でカメラ表示。
- 完成画像の確認：同じフォルダの `studio-front.png`。
- 再レンダー：`F12`。1920×1080、Cycles 48サンプル、ノイズ除去有効。
- レンダー画像の保存：レンダー画面の「画像 → 名前を付けて保存」。
- 編集後は「ファイル → 名前を付けて保存」で別名を付けると、この初期案を残せます。

マテリアルプレビューとCyclesの最終レンダーでは照明・反射の見え方が異なります。仕上がりの確認にはPNGまたはF12のレンダーを使ってください。

## 調整した部分

- 元の位置・間取りを維持し、木目、布・壁の細かな凹凸を手続き型の素材で追加。
- ガラスに透過・屈折、木材に控えめな表面コートを設定。
- 室内用の面光源、窓側の青い光、暖色のランプと廊下の照明を設定。
- このBlenderファイル内に天井を追加。元のGLBやブラウザ用の設定JSONは変更していません。
- 編集用ファイルを保存し、RTX 4060 Laptop GPUのOptiXで実際に静止画をレンダー。

キャラクター、歩行アニメーション、完成動画はまだ含みません。機材・椅子・窓外の街は簡略モデルのままです。実写相当の完成品ではなく、素材と照明を確認する最初の仕上げ案です。

## 再生成

このフォルダを作業ディレクトリにして実行します。`studio-finished-v01.blend` と `studio-front.png` を同名で更新するので、手動編集したファイルは先に別名で保存してください。

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python finish-studio.py
```

ユーザー全体のBlender設定は保存・変更していません。GPUの設定はこの実行中に行うため、別セッションで再レンダーする際は環境に応じて「編集 → プリファレンス → システム → Cyclesレンダーデバイス」でOptiXとRTX 4060を選んでください。CPUでもレンダーできます。

`import-report.json` に読み込み確認、`finish-report.json` にレンダー結果、`render.log` に実行ログを保存しています。
