6m × 5m × 高さ3mのスタジオと、入口につながる短い廊下を、個別の3Dオブジェクトで組み立てたローカル試作です。画像を立体風に表示する方式ではありません。今回は間取り・配色・配置・構図を見るための簡単なモデルです。

## 開く

リポジトリのルートで次を実行します。

```powershell
node experiments/studio-3d-20261001/server.mjs
```

ブラウザで [ローカルプレビュー](http://127.0.0.1:4318/) を開きます。サーバーは127.0.0.1だけに接続し、公開サイトにはしません。Three.jsは同梱しているため、起動後に外部CDNへアクセスしません。停止は実行したターミナルでCtrl+Cです。

## 見られるもの・操作

- 正面、斜め、入口の3構図と、壁の一部を隠す全体表示。
- ドラッグで回転、ホイールでズーム、右ドラッグで移動。
- 「入口から入る」で9秒のカメラ移動。衝突判定付きの歩行機能ではありません。
- 昼・夜の照明切り替え、字幕余白のガイド。
- 机・椅子・マイクとアーム・PC・ランプの位置変更。
- GLB・設定JSONの保存、設定JSONの再読み込み。

## 制作手順

1. **間取りを固定する。** 床中央を原点、単位m、Yを上方向とする。スタジオの奥は−Z、入口は＋Z。窓と入口は実際に壁が開いている形状。
2. **家具を別々の立体で作る。** 机、マイク、椅子、PC、ランプを名前付きのグループにまとめる。細部より大きさと配置を優先する。
3. **素材と照明を置く。** ネイビーの壁、矩形の吸音材、木のスラット、アンバーの実用灯。角に小さな面取りを入れ、影を落とす主光源は1灯にする。
4. **同じ空間に撮影位置を置く。** 正面・斜め・入口のカメラから、マイクや将来の猫、字幕の場所が成立するか確認する。
5. **雰囲気を確認して保存する。** 配置はJSONを正本とし、GLBは他ソフトへ渡す立体データとして書き出す。

## 編集の正本と保存ファイル

- `scene.json`：部屋、物体の位置・寸法・形状、照明、カメラ、将来の猫の配置アンカー。ここを編集してブラウザを再読み込みすると反映される。
- `materials.json`：素材名と色・粗さ・金属感・発光。色をまとめて管理する。
- `studio.js`：上記のデータから形状を作る表示コード。
- `exports/studio.glb`：名前付きの独立メッシュ、PBR素材、埋め込みサイン画像、カメラ、対応ライトを含む書き出し。ブラウザの全体表示で隠した壁も含める。
- `exports/studio-editable.json`：ブラウザで動かした配置と素材・照明・カメラ設定。画面の「設定JSONを読み込む」で復元する。
- `create-scene.mjs`：初期デザインを再作成する生成スクリプト。通常の起動では実行しない。実行すると `scene.json` と `materials.json` を初期案で上書きする。

「GLBを保存」「設定JSONを保存」は上記exports内の同名ファイルを更新します。複数案を残す場合は、保存後にファイル名を変えて保管してください。2026-10-01にBlender 5.2.2 LTSでGLBを実際に読み込み、素材と照明を調整した初回案を `blender/studio-finished-v01.blend` に保存しました。画像と開き方は [Blender仕上げ案](blender/README.md) を参照してください。ブラウザとBlenderで背景色、照明、影、トーンマッピングの見え方は異なります。
