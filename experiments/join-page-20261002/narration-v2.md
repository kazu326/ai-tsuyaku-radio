## 方針

- 採用済みの定義に合わせる。World Model Seed＝人と仕事をしながら育つ個別のAI作業単位（役割や経験ごとに違い、1人が複数持つこともある）、World Model Seed System＝共通の育て方と安全の約束
- 現在の実装済み機能ではなく、AI通訳ラジオが目指している設計の考え方として語る（新人ごとのSeedを自動で用意する仕組みは、まだない）
- 旧原稿の Persona、Human Signature、共通意味文法、Promotion Harness は使わない
- 耳で聞いて止まらないように、意味を先に言ってから名前を出す（以前の `context/CURRENT.md` にあった台本レビューの観点。現在は正本にない）
- 用語は読み上げが安定するようにカタカナで書く。英語表記は画面のラベルに任せる
- 演出タグは要所だけに少量使う。効果は実際の音声で確認する（`video/remotion/PROJECT_CONTEXT.md`）
- 例はすべて「例えば」として示す。実際に起きたことのように書かない

## 01_seed（ワールドモデルシードとは）

```text
AI通訳ラジオでは、完成したAI社員を、みんなに配ることはしません。

その代わりに目指しているのは、
あなたと一緒に仕事をしながら育っていくAIです。
私たちはこれを、ワールドモデルシードと呼んでいます。

最初のシードは、あなたのことを、まだほとんど知りません。
あなたが何をしたいのかも、
どんなやり方で仕事をしているのかも。

[short pause]
だから、一緒に仕事をします。
やってみて、
何が起きたかを見て、
うまくいかなかったことも、ちゃんと残す。

[warm]
そうやって、あなたの仕事に合ったAIに、
少しずつ育っていきます。

その育て方は、みんなに共通です。
この共通の育て方を、ワールドモデルシード・システムと呼んでいます。
```

画面：植物の比喩を流用。旧版の「全員共通の大きな種」は使わず、鉢ごとに育つ芽を「あなたのシード」、共通の土と手入れを「システム」とする。水・光・肥料のラベルは「やってみる」「何が起きた？」「残す」に置き換える案。

## 02_layers（共通の育て方と、人ごとの違い）

```text
では、何がみんなに共通で、
何が人ごとに違うのでしょうか。

みんなに共通なのは、育て方です。
どう仕事を始めて、どこで人に確認して、
経験をどう次に生かすか。
それから、危ないことをさせないための約束。
これが、ワールドモデルシード・システムの中身です。

[short pause]
その上に、人ごとに違うものが重なります。

一つ目は、どんな仕事で、どんな役割なのか。
そして、どこまで触ってよいと許されているのか。

二つ目は、その人が何を知っていて、
これまで何を経験してきたか。

そして三つ目が、今回の仕事の約束です。
今回は何をして、どこまでAIに任せるのか。

[short pause]
その約束の中では、どうしても難しいとき。
AIは勝手に範囲を広げずに、
「この条件では難しい」と伝えます。

同じ仕組みから始まっても、
役割や経験が違えば、
育つシードも、それぞれ違うものになります。
```

画面：4層のレイアウトを流用し、中身を入れ替える。

| 層 | ラベル | 補足 |
|---|---|---|
| 1 | World Model Seed System | 共通の育て方・安全の約束 |
| 2 | 仕事・役割・許可された範囲 | Organization / Role / Project / Permission |
| 3 | Personal Context / Experience | 何を知り、何を経験したか |
| 4 | Task Contract | 今回何をして、どこまで任せるか |

最後に「→ 役割や経験ごとに違う World Model Seed」へまとめる。旧版のまとめ「Seedは共通、RoleとPersonaは設計、Signatureは一緒に育てる」は使わない。

## 03_growth（経験から育つ）

```text
では、シードはどうやって育つのでしょう。

ポイントは、
一回の出来事を、すぐにルールにしないことです。

例えば、SNSに投稿してみたとします。
専門用語から書き始めた投稿は、あまり読まれなかった。
これは、実際に起きたこと。観察です。

[thoughtful]
そこから、
「身近な困りごとから書き始めた方が、伝わるのかもしれない」
という、発見の候補が生まれます。

[short pause]
でも、まだ候補です。
別の投稿でも、記事や動画でも、同じことが言えるのか。
何度か確かめて、
最後に人が見て、納得できたら。

そこで初めて、
「相手が知らない言葉から話し始めない」
という、次の仕事でも使える判断の土台になります。
これが、ワールドモデルです。

[warm]
うまくいかなかったことも、捨てません。
それも次に生かせる、大事な観察です。
```

画面：旧版の「日々のフィードバック → 共通意味文法 → Promotion Harness → 昇格・降格」は作り直す。

```text
Observation 何が起きた？
  ↓
Discovery 何が分かりそう？（候補）
  ↓
別の仕事でも確かめる
  ↓
Human Review
  ↓
World Model 次の仕事でも使える判断の土台
```

流れと条件は `context/ACTOR_WORLD_MODEL.md` に揃える。
