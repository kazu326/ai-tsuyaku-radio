説明この会社の仕組み

完成したAI社員を配る会社ではありません。

あなたと一緒に仕事をしながら育つAIがいます。最初は、あなたのことも、あなたの仕事のことも知りません。

あなたには

World Model Seed

あなたと一緒に仕事をしながら育つAI。仕事をするほど、あなたの仕事に合っていきます。

会社には

World Model Seed System

そのAIを、あなたの仕事と経験に合わせて育てる仕組み。危ないことをさせないための約束も、ここにあります。

覚える言葉は、この2つだけです。仕事の進め方は、5つの問いの繰り返しです。

  1. 何をしたい？
  2. →
  3. どこまでAIに任せる？
  4. →
  5. やってみる
  6. →
  7. 何が起きた？
  8. →
  9. 次はどうする？

うまくいかなかったことも、大事な記録になります。あなたもAIも、そこから育ちます。

裏側ではAIがTask Contract → 実行 → 必要ならChallenge → Observation → 更新として扱う（WORLD_MODEL_SEED_SYSTEM.md）。ページではこの用語を出さない。

実用初出勤の準備

5つの準備で、初出勤できます。

太字が入社の手続き、その下が実際にやることです。終わったらチェックを入れてください。この画面を閉じても、チェックは残ります。

0 / 5 完了

  1. GitHubは、AI通訳ラジオの仕事と記録が置いてある場所です。アカウントを作ったら、ユーザー名をProject Lead（@kazu326）に伝えてください。届いた招待メールの「Accept invitation」を押せば完了です。

  2. 公式サイト（git-scm.com）からインストールします。そのあと、ターミナル（WindowsはPowerShell、Macはターミナル）で次の2つを一度だけ実行します。名前とメールアドレスは自分のものに置き換えてください。

    git config --global user.name "Taro Yamada"
    git config --global user.email "taro@example.com"

  3. インストールとログインは、公式ガイドの手順どおりに進めます。Codex CLI公式ガイド

    利用には有料プランまたはAPIの利用が必要です（「先に知っておくこと」を参照）。

  4. 次の3つを、上から順に1つずつ実行します。

    git clone https://github.com/kazu326/ai-tsuyaku-radio.git
    cd ai-tsuyaku-radio
    git switch -c experiment-first-task
  5. codex

    起動したら、次の文章をそのまま貼り付けて送ります。

    私は新しいReal Memberです。このリポジトリの作業方針を確認してください。そのうえで、AIを使って何をやってみたいか一緒に整理し、最初の小さなExperimentを決めてください。必要なContextだけ読んでください。

ここから先は、AIと一緒に進めます。小さなExperimentを決めて、やってみて、何が起きたかをPRに残せば1周です。

最初の1周の手順をすべて見る（REAL_MEMBER_ONBOARDING）

コマンドとプロンプトは実装時に docs/REAL_MEMBER_ONBOARDING.md からビルド時に読み込む。ページに書き写さない。外部Contributor（fork）の手順はページでは扱わず、onboarding本文に任せる。
