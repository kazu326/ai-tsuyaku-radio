# AI通訳ラジオ本社：全体平面図

2026-10-01。ユーザーの一部採用・間取り制作依頼に基づく本社全体の設定図。外観と通路の素材感を起点に、上下階・扉・共用動線が同じ座標でつながる平面図を作成しました。Higgsfield生成0回・クレジット消費0です。

## 成果物

- `headquarters-floorplans.pdf`：A3横・3ページ。1ページ目が手書き風注釈版、2ページ目が注釈なし設計版、3ページ目が画像の参照範囲と仮定の説明。図面ページはA3原寸で1:100。印刷する場合は用紙に合わせる拡大縮小を切り、100%で印刷。
- `headquarters-annotated.png`：注釈版、約3969×2807px。Webや動画の世界観紹介に使える確認用画像。
- `headquarters-clean.png`：注釈なし。配置・寸法の照合用。
- `headquarters-annotated.svg` / `headquarters-clean.svg`：編集可能なベクター図。手書き風の公開フォントを埋め込み。本文はMeiryo等のシステムフォントを使用するため、環境により字幅が変わる場合がある。配布・印刷にはフォントを埋め込んだPDFが確実。
- `headquarters-layout.json`：本社外形、壁厚の仮定、部屋の内法範囲、接続口、窓、各階の高さ、収録区画への動線をメートルで記録。Blenderで立体化するときの正本。
- `verification.json`：部屋の重なり・外形内への収まり・扉接続・全室への接続・二室動線・上下階の階段一致の確認。

`07-headquarters-corridor.png` は通路の紺の壁、木の床・枠、暖色の照明だけを参考として部分採用。ユーザー指示により、画像内の斜め扉、共用廊下から録音室に直接入る構造、ブースの間取り・機材配置は採用していません。画像全体を正しい内部構造として扱わないでください。

これら以外の過去の画像・動画・3D試作は不採用のままです。採用記録は旧ライブラリのmanifestと `../studio-spatial-foundation-20261001/asset-policy.json` に反映。過去の画像・動画のファイル自体は変更していません。旧 `record-reset.py` は以前の一括不採用を記録する履歴用スクリプトなので、現行の一部採用を維持するには再実行しないでください。

## 今回の配置

建物外形は仮に幅16.0m×奥行11.6m、各階185.6m²、延べ371.2m²、階高3.4m。画像から奥行きや正確な寸法は確定できないため、今回の用途に合わせて寸法の整合を取った設定です。図上の北は便宜的な向きであり、敷地の実方位を決めたものではありません。

1階には受付・待合、主通路、メインの収録区画A、編集・技術室、資料・機材室、保管室、WC・設備庫、階段を配置。2階にはサブ収録区画B、編集・制作室、企画・ワーク室、打合せ・資料室、休憩・給湯、WC、階段を配置しました。

両階とも **共用通路 → コントロールルーム → 録音室** の順で接続。録音室への共用通路からの直通扉はありません。Aの仮枠は録音室19.2m²＋コントロール18.4m²、Bは録音室16.2m²＋コントロール15.6m²です。

## ユーザー作成のブース図を入れる境界

薄青の区画は、必要な広さと接続を確保するための仮枠です。机・マイク・PC・椅子を描いていません。二室間の仕切りと扉も仮接続口として破線で表しています。観察窓、扉の形式と位置、内殻、遮音層、室内の機材配置はユーザーの詳細図へ差し替えます。

ブース図が届いたら、区画の外形・天井高さ・コントロールへの入口・二室間の接続・外観のガラスとの関係を合わせます。区画に収まらない場合は本社側の隣接室・廊下を調整します。今回の仮寸法をユーザー図の制約として押し付けません。二室動線を確保した図であり、遮音性能や音響仕様を確定した図ではありません。

## 見せ方

壁・扉の開き・窓・寸法・スケールバーは通常の図面表現。補足だけに3色・3書体の手書き風文字と曲線矢印を加えました。字の大きさ、丸み、筆記の雰囲気を変え、複数人が書き込んだような見せ方にしています。注釈あり／なしの両方が同じ座標データから出ます。

手書き風フォントは [Yomogi](https://github.com/satsuyako/YomogiFont)、[Klee One](https://github.com/fontworks-fonts/Klee)、[Zen Kurenaido](https://github.com/googlefonts/zen-kurenaido)。Google Fonts公式リポジトリから取得したTTFと各OFLを `fonts/` に同梱。PC全体へのフォントインストールは行っていません。

```powershell

```
