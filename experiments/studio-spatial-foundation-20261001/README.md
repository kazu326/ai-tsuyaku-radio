## 旧3Dモデルの扱い

前回の3Dモデルは、正しい配置として承認されたものではありません。形状を再利用する場合も、新しい平面図に合わせて配置・向きを見直します。前回の画像を複数枚つなぎ合わせて間取りを推測しません。

## 現在の進め方

1. ユーザー作成の2階B詳細図で、机・ホスト席・PC・マイク・扉・観察窓・外窓等の位置と向きを決める。
2. 本社平面図の座標へ詳細図を反映する。
3. シンプルな形状で一つの3Dシーンを作る。
4. 家具と建築の座標・向きを固定し、カメラだけ変える。
5. 正面・後方・左右・俯瞰を同じ状態から出力し、空間整合性を確認する。
6. 配置確認後に、3Dレンダーを高品質画像生成の構図リファレンスとして使う方法を検証する。

生成AIによる別アングル画像だけで配置を確定しません。画面上の左右が変わることと、世界座標上で物体が移動・反転することを分けて判断します。
